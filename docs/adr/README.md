# Architecture Decision Records

Short, immutable records of architecturally significant decisions — each capturing one decision, its context, and its consequences. We don't edit a record once it's accepted; if a decision changes, we add a new ADR that supersedes the old one.

Format: [Michael Nygard's](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions.html) — Status, Context, Decision, Consequences. Start from [`template.md`](template.md).
